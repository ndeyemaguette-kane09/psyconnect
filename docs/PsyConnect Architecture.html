🔄 Flux typique — Patient réserve une consultation
1
Flutter envoie les credentials → API Gateway route vers Auth Service qui retourne un token JWT avec le rôle
2
ML Service (Python) analyse le profil patient et retourne une liste de psys recommandés via l'API Gateway
3
Patient choisit un créneau → Appointment Service crée la réservation en PostgreSQL
4
Payment Service contacte l'API Wave → confirme le paiement → déclenche le Notification Service
5
Notification Service envoie un SMS + push Firebase FCM au patient et au psy
6
À l'heure du RDV, Flutter lance la session via Agora SDK — le Session Service enregistre l'historique
