# Logiciels et environnements de développement — PsyConnect

## Environnements de développement (IDE)
- **IntelliJ IDEA** — développement des microservices Java (Spring Boot)
- **Visual Studio Code** — développement Flutter/Dart et Python
- **Android Studio** — émulation et tests Android

## Langages de programmation
- **Java 17** — back-end microservices
- **Dart** — application mobile Flutter
- **Python 3** — service de recommandation ML
- **SQL** — gestion des bases de données PostgreSQL

## Frameworks et plateformes
- **Spring Boot 3.5** — socle des microservices back-end
- **Spring Cloud** — gateway, découverte de services (Eureka), résilience
- **Spring AI** — intégration du modèle de langage (compagnon Xalaat)
- **Flutter** — application mobile iOS et Android (interface unique multi-rôles)
- **FastAPI** — API REST du service de recommandation (Python)

## Bases de données
- **PostgreSQL** — base de données relationnelle (une instance par microservice)

## Intelligence artificielle
- **Ollama** — runtime local pour les modèles de langage
- **qwen2.5:3b** — modèle de langage open source utilisé par Xalaat

## Infrastructure et déploiement
- **Docker** — conteneurisation des services
- **Docker Compose** — orchestration locale de l'ensemble de l'application
- **Zipkin** — traçage distribué des appels inter-services
- **Jitsi Meet** — visioconférence WebRTC pour les consultations en ligne

## Gestion de version et collaboration
- **Git** — contrôle de version
- **GitHub** — hébergement du dépôt

## Outils de documentation
- **PlantUML** — génération des diagrammes UML
- **Microsoft Word** — rédaction du cahier des charges et du mémoire
